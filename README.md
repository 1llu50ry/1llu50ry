## 🔬 Research &amp; Focus

<table>
  <tr>
    <td width="28%"><b>Binary Hardening</b></td>
    <td>Control Flow Flattening (CFF), instruction substitution, code virtualization (VM handler emulation), import address table obfuscation, and anti-tamper heuristics.</td>
  </tr>
  <tr>
    <td><b>Low-Level &amp; Kernel</b></td>
    <td>Windows kernel internals, undocumented structures, EPT / VT-x virtualization primitives, hypervisor-based introspection, and stealth memory allocation.</td>
  </tr>
  <tr>
    <td><b>Reverse Engineering</b></td>
    <td>Static and dynamic analysis with IDA Pro / Binary Ninja, automated struct and vtable reconstruction, deobfuscation scripts, and x86_64 assembly auditing.</td>
  </tr>
  <tr>
    <td><b>Game Internals</b></td>
    <td>Source 2 &amp; modern 3D engine reverse engineering, network packet serialization, fast detour hooking, hardware breakpoints, and memory forensics.</td>
  </tr>
</table>
